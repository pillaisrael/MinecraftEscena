# Escena Minecraft en Unity

Escena 3D inspirada en Minecraft, hecha en Unity con un terreno pintado con texturas
pixeladas y más de 200 cubos que forman árboles, paredes y una antorcha con luz.

## Requisitos
- Unity 6.6 (6000.6.4f1)
- Plantilla Universal 3D (URP)

## Cómo abrir el proyecto
1. Clona o descarga este repositorio.
2. Abre Unity Hub > Add > Add project from disk y elige la carpeta del proyecto.
3. Abre la escena en `Assets/Scenes/SampleScene`.
4. Presiona Play.

## Controles
- **W A S D:** moverse
- **Mouse:** mirar
- **Espacio:** saltar
- **Esc:** liberar el cursor

## Contenido de la escena
- Terreno con textura de pasto estilo Minecraft.
- Árboles, paredes y antorcha armados con cubos de 1x1x1.
- Materiales con texturas pixeladas (Filter Mode: Point).
- Antorcha con material emisivo y Point Light.
- Jugador en primera persona con script en C# (`JugadorFPS`).
